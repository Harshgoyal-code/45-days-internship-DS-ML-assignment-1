Q1. Difference Between Data Types
In Python, data types tell us what kind of value a variable holds. Here are the four basic ones:
a) Integer (int)
Integers are whole numbers – no decimal, no fraction. Can be positive or negative.
age = 20
year = 2024
print(type(age))   # Output: <class 'int'>
b) Float (float)
Floats are numbers with a decimal point, used when precision matters.
price = 99.99
pi = 3.14159
print(type(price))  # Output: <class 'float'>
c) String (str)
Strings are sequences of characters — basically any text. Written inside quotes.
name = "Gargi"
city = "Jaipur"
print(type(name))   # Output: <class 'str'>
d) Boolean (bool)
Booleans can only be True or False. Very useful in conditions and comparisons.
is_student = True
has_passed = False
print(type(is_student))  # Output: <class 'bool'>

Q4. Five Commonly Used String Methods
1. upper()
Converts the entire string to uppercase.
s = "hello world"
print(s.upper())   # Output: HELLO WORLD
2. lower()
Converts the entire string to lowercase.
s = "HELLO"
print(s.lower())   # Output: hello
3. strip()
Removes extra spaces from both ends of a string.
s = "   hello   "
print(s.strip())   # Output: hello
4. replace()
Replaces one part of a string with another.
s = "I love cats"
print(s.replace("cats", "dogs"))   # Output: I love dogs
5. split()
Splits a string into a list based on a separator.
s = "apple,mango,banana"
print(s.split(","))   # Output: ['apple', 'mango', 'banana']

Q7. What is Artificial Intelligence (AI)? Explain its importance and mention any four real-life applications of AI.
Artificial Intelligence (AI)

Artificial Intelligence (AI) is a branch of computer science that enables machines to perform tasks that normally require human intelligence. These tasks include learning, reasoning, problem-solving, decision-making, and understanding language.

Importance of AI
Automates repetitive tasks and increases productivity.
Reduces human errors and improves accuracy.
Helps in faster decision-making using data analysis.
Saves time and resources in various industries.
Enhances customer experience through intelligent systems.
Real-Life Applications of AI
1. Virtual Assistants

AI-powered assistants such as Siri and Alexa can understand voice commands and perform tasks.

2. Recommendation Systems

Platforms like Netflix and YouTube use AI to recommend movies and videos based on user preferences.

Q8. Which of These Are Examples of AI
ChatGPT  →  YES – AI
ChatGPT is a large language model that learns from huge amounts of text data. It understands
context, generates human-like responses, and improves through training. This is a classic example of
Generative AI.
Google Maps Route Prediction  →  YES – AI
Google Maps doesn't just follow fixed rules — it learns from real-time traffic data, predicts congestion,
and suggests the fastest route. This kind of adaptive decision-making is AI.
Calculator  →  NO – Not AI
A calculator simply follows fixed mathematical rules. It doesn't learn, adapt, or make decisions on its
own. It will always give the same output for the same input — no intelligence involved.
Netflix Recommendations  →  YES – AI
Netflix uses machine learning algorithms to study your watch history and preferences, then
recommends shows and movies you're likely to enjoy. It gets smarter over time — that's AI.
Voice Assistants (Alexa/Siri)  →  YES – AI
Alexa and Siri use Natural Language Processing (NLP) and machine learning to understand your
voice, interpret your intent, and give relevant answers. They also improve with use — definitely AI
